Matter

Air Quality Sensor

By What's Matter Inc.

This air-quality sensor measures fine and ultrafine particulate Matter in real time. It can integrate with smart-home devices to automatically control air purifiers and ventilation systems, and it promptly alerts users to harmful indoor pollution. Through a wireless network, real-time data can be viewed in a mobile app.

Product Details

  • Firmware Version 1.0
  • Hardware Version WM-2025-AQS1.0
  • Certificate ID CSA25F7BMAT48845-24
  • Certified Date 12/08/2025
  • Product ID 0xD003
  • Vendor ID 0x1594
  • Compliance Document Download Compliance Document
  • TIS/TRP Tested Yes
  • Specification Version 1.4
  • Transport Interface Thread
  • Primary Device Type ID 0x002C
